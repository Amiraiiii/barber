# 💈 BLACKLINE BARBERS — Отчёт о выполненной работе

**Бренд:** BLACKLINE BARBERS  
**Сlogan:** *"Sharp cuts. Clean confidence."*  
**Стиль:** Dark Luxury Editorial / Premium Barber Culture  
**Репозиторий:** Monorepo (`apps/web`, `apps/api`, `packages/db`)

---

## 📸 Стек технологий и архитектура

| Слой | Технологии | Описание |
| :--- | :--- | :--- |
| **Frontend Web** | Next.js 16 (App Router), TypeScript, CSS Modules, Lenis | Редакционный премиум-лендинг и интерактивная форма записи |
| **Backend API** | Fastify 5, TypeScript, Zod, CORS | Выделенный REST API сервер для обработки слотов и бронирований |
| **Database** | Prisma ORM 6, PostgreSQL (Supabase) | 12 таблиц БД, связи, сидирование данных и миграции |
| **Design System** | Vanilla CSS, HSL-палитра, Noise Grain | Черно-золотая/бронзовая палитра `#0C0C0C`, `#F2EDE4`, `#A89070` |

---

### 📅 Этап 2. Интерфейс пошаговой записи (`/book`)
- [x] **Отдельный роут `/book`:** Разработана 5-шаговая форма записи.
- [x] **Шаг 01 (Выбор услуги):** Сетка услуг с итоговой стоимостью и временем.
- [x] **Шаг 02 (Выбор мастера):** Карточки мастеров + уникальная опция **«Any Available Master»** (первый свободный).
- [x] **Шаг 03 (Дата и время):** Интерактивная лента дат на неделю + сетка свободных слотов (`10:00`, `11:00`, `12:00`, `14:00`, `15:00`, `16:30`, `18:00`, `19:30`).
- [x] **Шаг 04 (Данные клиента):** Форма ввода имени, телефона, email и примечаний.
- [x] **Шаг 05 (Экран подтверждения):** Успешная бронь с генерацией кодов (`BLK-XXXXX`) и быстрым возвратом.
- [x] **Боковая панель Summary:** Живой перерасчет информации о выбранном времени и стоимости.

---

### 🗄️ Этап 3. Схема базы данных (Prisma & PostgreSQL)
- [x] **Пакет [`packages/db`](file:///d:/Amira/full%20project/packages/db):** Выделенный пакет для работы с БД в монорепозитории.
- [x] **Prisma Schema (`12 моделей`):**
  - `services` — каталог услуг.
  - `barbers` — профили барберов.
  - `barber_services` — связи мастеров и услуг.
  - `working_hours` — график работы по дням недели.
  - `breaks` — обеденные перерывы.
  - `time_off` — отпуска и выходные.
  - `clients` — база клиентов.
  - `bookings` & `booking_services` — история записей и их состав.
  - `reviews` — отзывы после визитов.
  - `settings` — системные настройки.
  - `admin_users` — аккаунты администраторов.
- [x] **Скрипт сидирования [`seed.ts`](file:///d:/Amira/full%20project/packages/db/prisma/seed.ts):** Первичное заполнение услуг, барберов, графиков работы и тестового админа.

---

### ⚡ Этап 4. Backend API Сервер (`apps/api`)
- [x] **Fastify Сервер:** Настроен сервер на порту `4000`.
- [x] **CORS & Zod:** Настроена валидация входных данных и доступ для фронтенда.
- [x] **Эндпоинты API:**
  - `GET /health` — проверка статуса сервера.
  - `GET /api/v1/services` — получение списка всех услуг.
  - `GET /api/v1/barbers` — получение списка барберов.
  - `GET /api/v1/barbers/:id` — получение детальной информации о барбере и его услугах.

---

### ⏱️ Этап 5. Логика расчёта слотов и управление записью
- [x] **Расчёт доступности:**
  - `GET /api/v1/availability/days` — получение доступных дней с учётом выходных.
  - `GET /api/v1/availability` — расчёт свободных слотов с фильтрацией обедов (`14:00 - 15:00`), занятых временных отрезков и длительности услуг.
- [x] **Защита от оверлапинга:**
  - `POST /api/v1/bookings` — создание брони с выдачей уникального токена (`blk_...`). Возврат ошибки `409 SLOT_TAKEN` (код `23P01`) при совпадении времени.
- [x] **Страница клиента [`/booking/[token]`](file:///d:/Amira/full%20project/apps/web/src/app/booking/%5Btoken%5D):**
  - Клиентская страница просмотра деталей визита по ссылке/токену.
  - Логика отмены заказа (`POST /api/v1/bookings/:token/cancel`).
  - Логика переноса времени (`POST /api/v1/bookings/:token/reschedule`).
- [x] **Валидация сборки:** Сборка Next.js `npm run build:web` завершена с нулём ошибок.

## 🚀 Команды для запуска проекта

```bash
# 1. Установка всех зависимостей
npm install

# 2. Запуск фронтенда (Next.js на http://localhost:3000)
npm run dev

# 3. Запуск API сервера (Fastify на http://localhost:4000)
npm run dev:api

# 4. Генерация Prisma Client
npm run db:generate --workspace=packages/db
```
